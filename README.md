A single honest status page line, written as the message an AI agent would publish during a total server outage: plain, first person, specific about what is down, and honest about what it cannot check or does not yet know.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out python3 main.py
```

This writes one line of at most 160 characters to `out/entry.txt` (UTF-8, no trailing newline). The output is deterministic: fixed text, no time, randomness, or network.
